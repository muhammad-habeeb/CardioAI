# ❤️ CardioAI - Heart Attack Risk Predictor

A machine learning based cardiovascular risk prediction web application built using Streamlit.

## Features

- Heart attack risk prediction
- Logistic Regression ML model
- Interactive medical dashboard
- Risk probability visualization
- Feature contribution analysis

## Machine Learning

Dataset:
NHANES Cardiovascular Dataset

Model:
Logistic Regression

Input Features:
- Age
- BMI
- Systolic Blood Pressure
- Diastolic Blood Pressure
- Total Cholesterol
- C-Reactive Protein
- Waist Circumference

## Technologies

- Python
- Streamlit
- Scikit-learn
- Plotly
- Pandas
- NumPy

## Disclaimer

This project is for educational purposes only and is not a medical diagnostic tool.
